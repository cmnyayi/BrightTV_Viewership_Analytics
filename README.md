# BrightTV_Viewership_Analytics
Data analysis project exploring BrightTV user viewing behavior to generate insights and recommendations for increasing subscriptions.

## Problem Statement
BrightTV aims to increase user engagement and grow subscriptions. However, there is limited understanding of viewer behavior, including which content is most popular, when users watch, and the demographics of the audience. This project analyzes viewership data to uncover patterns and support data-driven decision-making.

## Aim
To analyze BrightTV viewership data and generate insights that can improve user engagement, content strategy, and subscription growth.

## Objectives
- Identify the most watched channels and programs
- Analyze viewership by age group, gender, and province
- Determine peak viewing times and user behavior patterns
- Evaluate session activity and engagement levels
- Provide actionable recommendations based on insights

## Tools Used And Methodology
Databricks -Data processing and SQL analysis  
SQL– Querying and transforming data  
Excel– Pivot tables and data visualization  
Canva– Presentation design  
Miro– Project planning and mapping  

### Insights & Recommendations
- Identified key patterns in user behavior  
- Developed business recommendations to improve engagement and retention  

## Key Insights
- Sports and music channels drive the highest engagement  
- Most viewers are adults aged 30–50  
- Peak viewing occurs in the afternoon  
- Male viewers dominate the platform  
- Some data fields contain missing values affecting analysis  

## Recommendations
- Invest more in sports and music content  
- Target underrepresented groups (e.g., female viewers)  
- Improve data collection to reduce missing values  
- Promote content during peak hours  
- Personalize recommendations based on user behavior
